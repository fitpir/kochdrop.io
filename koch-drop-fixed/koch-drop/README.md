# Koch Drop

Неофициальный фанатский симулятор кейсов CS2 с **виртуальным балансом**: кейсы, инвентарь, апгрейды, режим «Краш», промокоды, вход через Steam и админ-панель. PHP-сервер считает дроп, шансы, баланс и апгрейды, поэтому админка влияет на всех игроков.

> Реальные деньги, платежи и вывод средств не поддерживаются и не должны добавляться: это превратит проект в азартные игры, на которые нужна лицензия. CS2 и предметы принадлежат Valve; проект с Valve не связан.

## Структура

```
public_html/
  index.html          интерфейс
  api.php             сервер: дроп, шансы, баланс, Steam-вход, админка
  steam-check.php     диагностика хостинга (после настройки удалите)
  config.example.php  шаблон настроек -> скопируйте в config.php
  data/defaults.json  каталог по умолчанию (скины, кейсы, шансы, цены)
  data/               игроки и правки админки (JSON, создаётся сам, закрыт .htaccess)
.github/workflows/    проверка кода и выгрузка на Beget
```

## Быстрый старт локально

Нужен PHP 7.4+ (лучше 8.x).

```bash
cp public_html/config.example.php public_html/config.php   # впишите свои значения
php -S localhost:8000 -t public_html
```

Откройте http://localhost:8000. Вход через Steam на `localhost` может не сработать; для проверки входа используйте домен с HTTPS.

## Настройка (`config.php`)

| Параметр | Что это |
| --- | --- |
| `steam_api_key` | Ключ с <https://steamcommunity.com/dev/apikey> (ник и аватар; без него вход работает, ник будет «Steam 123456») |
| `admin_ids` | Ваш SteamID64 (17 цифр) в кавычках, например `['76561198000000000']` (узнать: <https://steamid.io>) |
| `admin_pin` | Ваш PIN админки (пока пусто, админка закрыта; не ставьте 1234) |
| `base_url` | Обычно пусто. Нужно, только если сайт за прокси и адрес определяется неверно |

`config.php` в `.gitignore`: ключи и PIN не попадут на GitHub. Если случайно закоммитили, смените ключ Steam API и PIN.

## Выгрузка на GitHub

```bash
git init -b main
git add .
git commit -m "Koch Drop: первая версия"
git remote add origin https://github.com/<ваш-логин>/koch-drop.git
git push -u origin main
```

Или через сайт: **New repository** → **uploading an existing file** → перетащите содержимое папки (включая скрытые `.github` и `.gitignore`).

> **GitHub Pages здесь не подойдёт, как и любой статический хостинг без PHP:** Pages отдаёт только статические файлы, а PHP (`api.php`) на нём не выполняется. GitHub нужен как хранилище кода, а сайт запускается на хостинге с PHP (например, Beget).

## Запуск на Cloudflare Workers (workers.dev)

Cloudflare **не выполняет PHP**: если выложить сюда `public_html/` как есть, то `/api.php` отдаётся как обычный файл и браузер его скачивает (так «ломался» вход через Steam). Для Cloudflare серверная часть переписана на JS: `src/worker.js` (всё то же самое: дроп, баланс, Steam-вход, админка), а `index.html` остаётся без изменений. Данные игроков хранятся в Durable Object (SQLite), включено в бесплатный план.

```bash
npm install
npx wrangler secret put ADMIN_IDS      # ваш SteamID64, например 76561198000000000
npx wrangler secret put ADMIN_PIN      # PIN админки
npx wrangler secret put STEAM_API_KEY  # необязательно (ник и аватар)
npx wrangler deploy
```

Имя Worker в `wrangler.toml` (`koch-drop-io`) должно совпадать с тем, под которым сайт уже задеплоен, иначе создастся новый. Секреты можно задать и в панели: Workers & Pages → ваш Worker → Settings → Variables and Secrets. Если репозиторий подключён к Cloudflare (Workers Builds), деплой пойдёт при каждом push; в настройках сборки команда деплоя `npx wrangler deploy`, корень проекта `/`.

Локальная проверка: создайте `.dev.vars` (`ADMIN_IDS=...`, `ADMIN_PIN=...`) и запустите `npx wrangler dev`. PHP-версия в `public_html/` остаётся для Beget.

## Установка на Beget

1. «Сайты» → домен с PHP 7.4+ (лучше 8.x). Выпустите бесплатный SSL (Let's Encrypt) и включите редирект на HTTPS.
2. Загрузите **содержимое** `public_html/` в папку сайта (файловый менеджер/FTP), включая скрытый `.htaccess` и папку `data/`. Создайте на сервере `config.php` из `config.example.php`.
3. Откройте `https://ваш-домен/steam-check.php`: все пункты должны быть «OK» (папка `data/` доступна на запись: права 755, при необходимости 775).
4. Заполните `config.php`, зайдите на сайт → «Steam» → войдите → «Админ» → PIN.

### Автовыгрузка через GitHub Actions (необязательно)

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Пример |
| --- | --- |
| `FTP_SERVER` | FTP-хост из панели Beget |
| `FTP_USERNAME` | FTP-логин |
| `FTP_PASSWORD` | FTP-пароль |
| `FTP_DIR` | Папка сайта, например `/ваш-домен/public_html/` (слэш в конце обязателен) |

Затем **Actions → Выгрузка на Beget → Run workflow**. Файлы `config.php`, `data/config.json` и `data/users/*.json` не затираются: они живут только на сервере.

## Админка

Вход только для Steam-аккаунтов из `admin_ids` и с PIN (проверка на сервере).

- **Игроки:** баланс, «удача» на редкие дропы, бонус к шансу апгрейда, выдача скина, удаление.
- **Скины:** добавление, удаление, правка названия, редкости, цены, эмодзи и картинки. Кнопка «Редкость и картинки из каталога CS2» подтягивает данные по названию (нужен интернет у администратора), затем «Сохранить всё».
- **Кейсы:** добавление, удаление, скрытие, цена, описание, состав и свои шансы по редкостям.
- **Шансы:** общие веса редкостей, промокоды, ставки Краша, стартовый баланс, журнал действий.

Игрок видит свой бонус удачи и апгрейда в профиле. Цены в виртуальных ₽ — ориентиры рынка Steam на конец 2026 (≈80 ₽/$, средний износ); рынок меняется, правьте в админке. Цены кейсов подобраны под средний возврат ≈90%, иначе баланс игроков растёт бесконечно.

## Резервная копия

Копируйте папку `data/` с сервера: там все игроки и каталог (в репозиторий она не попадает).
